Vraag: Wat is het verschil met de script tag boven in te laden in de < head > tag t.o.v onder inladen aan het einde van je HTML tag

Antwoord: Het verschil is dat scripts in de < head > tag worden geladen voordat de pagina wordt weergegeven, terwijl scripts aan het einde van de < body > tag worden geladen nadat de pagina is geladen.


Wat doet de attribuut “defer” in de < script > tag

Antwoord: Het attribuut “defer” zorgt ervoor dat het script pas wordt uitgevoerd nadat de HTML-pagina volledig is geladen. Dit betekent dat het script niet blokkeert tijdens het laden van de pagina, waardoor de pagina sneller kan worden weergegeven.


Wat is het verschil tussen HTML en JavaScript?

Antwoord: HTML (HyperText Markup Language) is een opmaaktaal die wordt gebruikt om de structuur en inhoud van webpagina's te definiëren. Het beschrijft elementen zoals tekst, afbeeldingen, links en formulieren. JavaScript daarentegen is een programmeertaal die wordt gebruikt om interactieve functionaliteit aan webpagina's toe te voegen. Het kan worden gebruikt om dynamische inhoud te creëren, gebruikersinteracties te verwerken en de DOM (Document Object Model) te manipuleren.


Bonus: Wat is het verschil tussen innerHTML en innerText?

Antwoord: Het verschil tussen innerHTML en innerText is dat innerHTML de HTML-inhoud van een element retourneert of instelt, inclusief eventuele HTML-tags, terwijl innerText alleen de zichtbare tekstinhoud van een element retourneert of instelt, zonder HTML-tags. Met andere woorden, innerHTML kan HTML-structuren bevatten, terwijl innerText alleen de tekst weergeeft zoals deze op de pagina wordt weergegeven.
